Listas

Lista ordenada

Para criar uma lista ordenada, use a tag <ol> para envolver a lista e a tag <li> para cada item da lista. A lista ordenada é numerada automaticamente.

  1. Primeiro item
  2. Segundo item
  3. Terceiro item

Porém, se você quiser personalizar a numeração, pode usar o atributo "type" na tag <ol>.

  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  1. Primeiro item
  2. Segundo item
  3. Terceiro item
  1. Primeiro item
  2. Segundo item
  3. Terceiro item

E pode começar em um número específico usando o atributo "start" na tag <ol>.

  1. Primeiro item
  2. Segundo item
  3. Terceiro item

Lista não ordenada

Para criar uma lista não ordenada, use a tag <ul> para envolver a lista e a tag <li> para cada item da lista. A lista não ordenada é marcada com marcadores (bolinhas).

  • Primeiro item
  • Segundo item
  • Terceiro item

Você pode personalizar os marcadores usando o atributo "type" na tag <ul>.

  • Primeiro item
  • Segundo item
  • Terceiro item

  • Segundo item
  • Terceiro item

  • Segundo item
  • Terceiro item

Lista de definição

Para criar uma lista de definição, use a tag <dl> para envolver a lista, a tag <dt> para cada termo e a tag <dd> para cada definição.

Listas aninhadas

Você pode criar listas aninhadas, ou seja, listas dentro de outras listas. Para isso, basta colocar uma lista dentro de um item de outra lista.

  1. Motivos para minha mulher ser bonita
    • Deusa
    • Gostosa
    • Maravilhosa
    • Peituda
    2. mais motivos para minha mulher ser bonita
    1. única bonita
    2. 0 concorrência
    3. Insuperável
    4. Peituda

    3. Ainda poderia misturar listas ordenadas e não ordenadas e dar continuidade aos pontos, eu poderia dar sequência a duas <ol> e <ul> e iniciar a segunda com "start " de onde parou (isso vale mais para a lista ordenada, já que a não ordenada não tem numeração).
