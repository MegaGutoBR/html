Tem outro modo de colocar audio, em varios formatos de maneira (que eu achei) rapida, é abrir a tag audio e colocar as tags source dentro dela, cada uma com um formato diferente, assim o navegador vai escolher o formato que ele suporta. A tag source tem outra src dentro; vc muda o type de acoro com o tipo do arquivo e a ordem pela prioridade.
Existe mais comandos alem do "controls", a exemplo do autoplay; preload (que é para definir se deve pré carrgar, esperar o usuário carregar ou não carregar); e o loop.

VAI SER UM VIDEO, SÓQ EU DINÂMICO

O video é mais complexo que o audio, tem mais comandos e mais coisas para se preocupar, mas é a mesma coisa, tem a tag video, dentro dela tem as tags source, cada uma com um formato diferente, e o navegador escolhe o formato que ele suporta. A tag video tem outros comandos alem do controls, como autoplay; preload (que é para definir se deve pré carrgar, esperar o usuário carregar ou não carregar); loop; poster (que é para definir uma imagem de capa para o video); e o muted (que é para deixar o video sem som).

Tem e é mais adequado adicionar video externo.

Para adicionar um video externo, é só usar a tag iframe, dentro dela tem o src do video, e o width e height para definir o tamanho do video. O video externo mais comum é o do youtube, mas tem outros sites de hospedagem de video que também permitem a incorporação de videos, como o vimeo.
