NESSA PAGINA EU SEPAREI PARA TER EXPLICAÇÃO DO NOFOLLOW

O atributo "rel" com o valor "nofollow" é usado para indicar aos motores de busca que eles não devem seguir o link ou passar autoridade de página para o destino do link. Isso é útil para evitar spam ou para links pagos, onde você não quer que o link influencie os rankings de busca.

Quando um link tem o atributo "rel" definido como "nofollow", os motores de busca não consideram esse link como um voto de confiança para a página de destino. Isso significa que o link não contribui para o ranking da página de destino nos resultados de busca.
