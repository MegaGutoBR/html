PRINCIPAIS FORMATAÇÕES DE TEXTO

negrito / destaque

negrito faz com B, que tem uma função não semântica e mais visual

destaque faz com STRONG, que tem uma função mais semântica

itálico / ênfase

itálico faz com I, que tem uma função não semântica e mais visual

ênfase faz com EM, que tem uma função mais semântica

Texto marcado

marcado faz com MARK, que tem uma função mais visual de marcação de texto

Letra grande e letra pequena

grande faz com BIG, que tem uma função mais visual de deixar o texto grande (por isso entrando em desuso)

pequeno faz com SMALL, que tem uma função mais visual (porém nem tanto) de deixar o texto pequeno

Texto deletado

deletado faz com DEL, que tem uma função mais semântica de marcar o texto como deletado

Texto inserido / Texto sublinhado

inserido faz com INS, que tem uma função mais semântica de marcar o texto como inserido

sublinhado faz com U, que tem uma função mais visual de deixar o texto sublinhado (não semântica)

Texto sobrescrito

para inserir coisas do tipo X2+3

Texto subscrito

para inserir coisas do tipo H2O

ATALHO

Tem um atalho legalzinho que é o CRTL+SHIFT+P, esse atalho serve para deixar as coisas sob uma função bem mais rápido. Exemplo:
>escreve algo
>esse algo devia estar em algua formatação
>seleciona o que devia estar
>utiliza do atalho
>pesquisa
>a depender da posição que tiver, é só buscar e dar enter, ou dar enter direto
